## 🚀 Overview

**StyleDecor Backend** powers a full-featured decoration service platform including:

- 👤 User authentication (Firebase JWT)
- 🎯 Role-based access (Admin / Decorator / User)
- 🛎 Service listing & management
- 📦 Booking & assignment system
- 💳 Stripe payment integration
- 📊 Real-time dashboard analytics
- 📬 Subscription & messaging system
